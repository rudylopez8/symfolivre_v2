# Backlog - symfoLivre

Ce backlog priorise les tâches selon la méthode MoSCoW :
- **Must have (M) :** Indispensable pour le fonctionnement de base.
- **Should have (S) :** Important mais peut attendre une V1.1.
- **Could have (C) :** Optionnel, confort pour l'utilisateur.
- **Won't have (W) :** Pas prévu pour ce cycle.

| Priorité | User Story / Fonctionnalité | Rôle |
| :--- | :--- | :--- |
| **M** | Inscription et authentification (Login/Logout) | Tous |
| **M** | Consulter la liste des livres (Page d'accueil) | Visiteur |
| **M** | Voir les détails d'un livre | Visiteur |
| **M** | Recherche de livre (titre, auteur, catégorie) | Visiteur |
| **M** | Téléchargement de fichiers (.txt, .md, .zip) | Lecteur |
| **M** | Téléversement de livres (avec validation type) | Auteur |
| **M** | Gestion des rôles et accès aux routes (Security) | Admin |
| **M** | CRUD complet sur les Livres et Catégories | Admin |
| **S** | Lecture en ligne des fichiers texte (.txt/.md) | Lecteur |
| **S** | Panier de lecture (persistance en base) | Lecteur |
| **S** | Modification/Suppression de ses propres livres | Auteur |
| **S** | API de recherche (Endpoint JSON) | API Client |
| **C** | Pagination et tri des résultats de recherche | Tous |
| **C** | Profil utilisateur (modification info perso) | Lecteur/Auteur |
| **C** | Barre de progression de lecture | Lecteur |
| **W** | Système de commentaires et avis | Lecteur |
| **W** | Système de recommandation automatique | Lecteur |
